복습

CNN은 translation에 “어느 정도만” 강했습니다

Convolution → equivariance

입력이 이동하면 feature map도 같이 이동합니다.

f(Tδx) = Tδ f(x)

Pooling → 국소적인 invariance

작은 이동은 흡수하지만, stride·padding·경계 때문에 큰 이동에는 출력이 흔들립니다.

그래서 마지막 실험: 데이터를 움직였다

“위치가 달라져도 이건 같은 숫자다”를 모델이 직접 보게 함 → 우리가 원하는 invariance

g(Tδx) ≈ g(x)

Part 2 · Distribution Shift

P(x, y) = P(x)·P(y|x) = P(y)·P(x|y) — 어느 항이 바뀌었나?

Covariate shift

P(x)가 바뀌고 P(y|x)는 유지

예: 낮 사진 → 밤 사진. “자동차”의 정의는 같지만 입력의 모습이 달라짐. DA가 주로 다루는 가정

Label shift (prior shift)

P(y)가 바뀌고 P(x|y)는 유지

예: 독감 유행기에 양성 비율 급증. 증상의 모습은 같지만 클래스 비율이 달라짐. → 예측 확률 재보정(re-weighting)

Concept shift

P(y|x) 자체가 바뀜

예: 스팸의 기준 변화, 병원마다 다른 진단 기준. 같은 x에도 정답이 달라지므로 target label 없이는 해결 불가

실제로는 섞여서 나타납니다. Subpopulation shift(소수 그룹 비율 변화), temporal drift 등도 함께 연구됩니다.

Part 2 · Distribution Shift

Shift가 있는지 어떻게 알 수 있을까?

Domain classifier test

source vs target을 구분하는 분류기를 학습. 정확도가 50%보다 크게 높으면 두 분포는 구분 가능 = shift 존재

통계적 거리

feature 공간에서 MMD, Fréchet distance, KL 등으로 두 분포 거리 측정

모델 신호 모니터링

평균 confidence 하락, 예측 entropy 증가, 예측 클래스 비율 변화

“흔들어보는” 벤치마크

  • ImageNet-C: noise, blur, weather, digital 계열 corruption을 5단계 강도로 적용 (Hendrycks & Dietterich 2019)
  • ImageNet-R / Sketch: 렌더링·스케치 스타일
  • WILDS: 병원, 지역, 시간, 사용자 등 실제 배포 환경의 shift 모음 (Koh et al. 2021)
  • DomainBed: domain generalization 방법들을 같은 조건에서 비교 (Gulrajani & Lopez-Paz 2021)

DomainBed의 교훈: 공정하게 튜닝한 ERM(그냥 모아서 학습) + 좋은 augmentation이 생각보다 강한 baseline입니다.

Part 3 · Domain Adaptation

이론적 직관: target error는 세 가지로 묶입니다

εT(h) ≤ εS(h) + ½ dℋΔℋ(𝒟S, 𝒟T) + λ*Ben-David et al., 2010

① Source error

source에서 잘 맞혀야 함. label이 있으니 일반적인 supervised learning으로 줄일 수 있음

② Domain divergence

분류기 입장에서 두 domain이 얼마나 구분 가능한가. feature 공간에서 이 값을 줄이는 것이 대부분 DA 방법의 핵심

③ λ* : 이상적 공동 오차

두 domain 모두에서 잘 맞히는 h가 존재하는가. 이게 크면(예: concept shift) 어떤 정렬로도 해결되지 않음

→ 전략: label로 ①을 줄이고, unlabeled target으로 ②를 줄인다. 단, 정렬 과정에서 ③이 커지지 않도록 주의해야 합니다. 다음 슬라이드에서 직접 확인해봅니다.

Part 3 · 방법 ① Discrepancy 기반

두 feature 분포의 통계량을 직접 맞추기

MMD (Maximum Mean Discrepancy)

MMD² = ‖ 𝔼S[φ(z)] − 𝔼T[φ(z)] ‖²ℋ

kernel로 매핑한 평균이 같아지도록 → 사실상 모든 차수의 moment를 맞춤

DDC (Tzeng et al. 2014), DAN (Long et al. 2015), JAN (Long et al. 2017)

CORAL (Correlation Alignment)

ℒCORAL = ¼d² ‖ CS − CT ‖²F

2차 통계량(공분산)만 맞춤. 구현이 매우 간단하고 안정적

CORAL (Sun et al. 2016), Deep CORAL (Sun & Saenko 2016)

# Deep CORAL loss (PyTorch) — 기존 학습 루프에 한 줄 추가하면 됩니다
def coral(zs, zt):
    d = zs.size(1)
    cs = torch.cov(zs.T); ct = torch.cov(zt.T)
    return ((cs - ct) ** 2).sum() / (4 * d * d)

loss = F.cross_entropy(clf(zs), ys) + lam * coral(zs, zt)   # zt는 label 불필요
Part 3 · 방법 ② Adversarial

DANN: domain을 구분하지 못하는 feature를 만들기

E(θf,θy,θd) = ℒy − λℒd   minθf,θy · maxθd

Gd는 domain을 맞히려 하고, Gf는 GRL을 통해 뒤집힌 gradient를 받아 구분되지 않는 feature를 만듭니다. GAN의 generator–discriminator 관계와 같습니다.

class GradReverse(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, lam):
        ctx.lam = lam
        return x.view_as(x)
    @staticmethod
    def backward(ctx, g):
        return -ctx.lam * g, None

Ganin & Lempitsky 2015 · Ganin et al. JMLR 2016
후속: ADDA (Tzeng et al. 2017), CDAN (Long et al. 2018), MCD (Saito et al. 2018)

λ는 0에서 시작해 점점 키우는 schedule이 흔히 쓰입니다.

target을 모르겠다면, source의 변화를 현실보다 훨씬 넓게 만들어서 현실이 그 중 하나가 되도록 함

  • weak aug로 label 만들고 strong aug로 학습 (FixMatch식 일관성)
  • 위험: 틀린 pseudo-label이 누적되는 confirmation bias

CBST (Zou et al. 2018), DAFormer (Hoyer et al. 2022)

Normalization 통계 교체

BatchNorm의 평균·분산을 target 데이터로 다시 계산

x̂ = (x − μT) / σT

학습 없이 몇 줄로 적용 가능한 강력한 baseline

AdaBN (Li et al. 2016)

Test-time / Source-free

TENT: 테스트 batch의 예측 entropy를 최소화하도록 BN의 affine 파라미터만 업데이트

H(ŷ) = −Σc p(ŷc) log p(ŷc)

SHOT: source 분류기는 고정하고, 정보 최대화 + pseudo-label로 feature extractor만 적응

Wang et al. 2021 · Liang et al. 2020

여기서도 augmentation이 다시 등장합니다: 서로 다른 augmentation view의 예측이 일치하도록 만드는 것이 self-training의 핵심 신호입니다.

다음 실습 제안

MNIST → MNIST-M으로 직접 확인해보기

실험 단계

  1. Source only: MNIST로만 학습 → MNIST-M 정확도 측정
  2. + Augmentation: color jitter, 반전, 노이즈 추가 → 얼마나 좁혀지는가?
  3. + AdaBN: target 데이터로 BN 통계만 다시 계산
  4. + DANN: unlabeled MNIST-M으로 GRL 학습
  5. Target oracle: MNIST-M label로 학습 (상한선)

각 단계를 같은 backbone, 같은 epoch으로 비교하고, t-SNE로 source/target feature 분포를 그려봅니다.

생각해볼 점

  • target label 없이 λ와 epoch은 어떻게 고를까? (검증 전략 문제)
  • t-SNE에서 두 domain이 섞였다고 정확도가 반드시 올랐을까? (클래스 뒤바뀐 정렬 데모 참고)
  • MNIST → SVHN으로 방향을 바꾸면 어떤 방법이 먼저 무너질까?

MNIST-M은 DANN 논문에서 MNIST 숫자에 BSDS500 사진 패치를 합성해 만든 데이터셋입니다.

요약

오늘의 흐름

Data Augmentation

데이터 개수가 아니라 불변성에 대한 약속. 변환이 label을 보존하는지는 task가 결정

Distribution Shift

PS(x,y) ≠ PT(x,y). 어떤 항이 바뀌었는지(covariate / label / concept)에 따라 해법이 다름

Domain Adaptation

unlabeled target으로 domain 차이를 줄임. 통계 정렬, adversarial, pixel-level, self-training
