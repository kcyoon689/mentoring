01 개념과 유형

이미지 세그멘테이션이란?

객체가 "어디쯤" 있는지가 아니라, 정확히 "어느 픽셀"인지

정의

이미지 세그멘테이션(Image Segmentation)은 이미지의 모든 픽셀에 클래스 레이블을 할당해 이미지를 의미 있는 영역으로 나누는 기술입니다. 결과물은 입력과 같은 크기의 레이블 맵(마스크)이며, 객체의 정확한 형태와 경계까지 표현합니다.

이미지 분류
이미지 전체 → 레이블 1개
객체 탐지 (Part 1)
객체마다 클래스 + 사각형 박스 · 대략적 위치
세그멘테이션
픽셀마다 클래스 · 정확한 형태와 경계

왜 박스로는 부족한가?

  • 박스 안에는 객체와 배경이 섞여 있음 (기울어진 차, 사람의 팔 사이)
  • 도로·하늘처럼 형태가 정해지지 않은 영역은 박스로 표현하기 어려움
  • 면적·부피 측정, 정밀한 경계가 필요한 작업에는 픽셀 정보가 필수

주요 활용 분야

  • 자율 주행: 주행 가능 영역, 차선, 보행자 영역 분할
  • 의료 영상: 종양·장기 경계 분할, 크기 측정
  • 위성·항공: 토지 피복, 건물·도로 추출
  • 영상 편집: 인물 배경 제거, 가상 배경
01 개념과 유형

세그멘테이션의 세 가지 유형

같은 장면도 "무엇을 구분하느냐"에 따라 결과가 달라진다

시맨틱 세그멘테이션

Semantic Segmentation

모든 픽셀을 클래스로 분류합니다. 같은 클래스면 같은 레이블이므로 두 자동차는 하나의 "차량" 영역이 됩니다.

답하는 질문

"이 픽셀은 무엇인가?"

대표 모델

FCN, U-Net, DeepLab, SegFormer

평가 지표: mIoU

인스턴스 세그멘테이션

Instance Segmentation

셀 수 있는 객체(Thing)를 찾아 개체마다 별도의 마스크를 만듭니다. 두 자동차가 서로 다른 인스턴스로 구분되며, 배경은 다루지 않습니다.

답하는 질문

"이 픽셀은 어느 객체의 것인가?"

대표 모델

Mask R-CNN, YOLACT, SOLO

평가 지표: mask AP

파놉틱 세그멘테이션

Panoptic Segmentation

두 방식을 통합해 모든 픽셀에 클래스를 주고, Thing(차·사람)은 인스턴스 ID까지 부여합니다. Stuff(하늘·도로)는 클래스만 가집니다.

답하는 질문

"무엇이며, 몇 번째 객체인가?"

대표 모델

Panoptic FPN, Mask2Former

평가 지표: PQ = SQ × RQ
02 핵심 원리

픽셀 단위 예측의 딜레마와 인코더–디코더

"무엇(what)"을 알려면 줄여야 하고, "어디(where)"를 지키려면 줄이면 안 된다

분류용 CNN은 풀링·stride로 해상도를 1/32까지 줄이며 의미 정보를 얻지만, 그 과정에서 위치 정보를 잃습니다. 세그멘테이션은 입력과 같은 해상도로 픽셀마다 답해야 하므로, 줄였다가 다시 키우는 구조가 필요합니다.

입력 H×W×3 → 출력 H×W×C
(픽셀별 C개 클래스 점수 → argmax)

인코더 (Encoder)

사전학습된 분류망(VGG, ResNet 등)으로 특징을 추출. 깊어질수록 해상도는 작아지고 무엇인지에 대한 정보가 풍부해집니다.

디코더 (Decoder)

작아진 특징맵을 단계적으로 업샘플링해 원래 해상도로 복원하고, 마지막 1×1 conv로 픽셀마다 C개 클래스 점수를 냅니다.

스킵 연결 (Skip Connection)

인코더 초기 층의 세밀한 위치·경계 정보를 디코더에 직접 전달해, 업샘플링만으로는 복원하기 어려운 디테일을 되살립니다.

02 핵심 원리

업샘플링: 해상도를 어떻게 되살리는가

디코더의 핵심 연산, 작은 특징맵을 큰 특징맵으로

보간 (Interpolation)

Nearest · Bilinear

주변 값들의 거리에 따른 가중 평균으로 새 픽셀 값을 채웁니다. 학습 파라미터가 없어 가볍고 안정적이며, 보간 후 conv를 붙여 보완하는 경우가 많습니다.

사용 예: FCN(초기화), DeepLab 출력 복원

전치 합성곱

Transposed Convolution

입력 값 하나하나에 학습된 커널을 곱해 넓은 출력에 뿌려 더합니다. stride 2면 해상도 2배. 업샘플링 방식 자체를 데이터로 학습합니다.

주의: 커널이 겹치며 체커보드 무늬가 생길 수 있음

맥스 언풀링

Max Unpooling

인코더의 max pooling 때 최댓값이 있던 위치를 기억해 두었다가, 그 자리에 값을 되돌려 놓고 나머지는 0으로 채웁니다.

사용 예: SegNet (메모리 효율적인 경계 복원)
마지막 단계  원래 해상도로 복원된 특징맵에 1×1 conv를 적용해 채널 수를 클래스 수 C로 맞추고, 픽셀마다 Softmax → argmax로 최종 레이블 맵을 만듭니다.
03 대표 모델

FCN: 세그멘테이션의 출발점 (2015)

Fully Convolutional Network — 분류망을 픽셀 예측망으로 바꾸다

핵심 아이디어

  • 분류망(VGG-16)의 마지막 FC 층을 1×1 conv로 교체
  • FC 층은 고정 크기 입력만 받고 위치 정보를 버리지만, conv로 바꾸면 임의 크기 입력에 대해 클래스별 공간 히트맵이 출력됨
  • ImageNet 사전학습 가중치를 그대로 재활용해 end-to-end로 픽셀 예측 학습
conv1–3pool3 · 1/8
→
conv4pool4 · 1/16
→
conv5pool5 · 1/32
→
1×1 conv클래스 점수 맵

의의와 한계

  • 의의: "인코더 + 업샘플링 + 스킵"이라는, 이후 거의 모든 세그멘테이션 모델의 기본 틀을 제시
  • 한계: 1/32까지 줄어든 특징에서 복원하므로 경계가 뭉개지고, 넓은 문맥(전역 정보) 활용이 부족
  • 이 한계를 U-Net(정교한 디코더)과 DeepLab(해상도 유지 + 다중 스케일)이 각각 다른 방식으로 해결
스킵 구조에 따른 세 가지 변형

FCN-32s

pool5(1/32)의 예측을 한 번에 32배 업샘플. 가장 단순하지만 결과가 거칠고 뭉툭합니다.

FCN-16s

pool5 예측을 2배 업샘플해 pool4 예측과 합산 후 16배 업샘플. 경계가 개선됩니다.

FCN-8s

위 결과를 다시 2배 업샘플해 pool3 예측까지 합산 후 8배 업샘플. 세 변형 중 가장 정밀합니다.

왼쪽 그림: 같은 원형 객체를 거친 해상도에서 복원할수록 경계가 계단처럼 뭉개지는 모습
03 대표 모델

U-Net: 대칭형 인코더–디코더 (2015)

의료 영상에서 출발해, 가장 널리 쓰이는 세그멘테이션 구조가 되다

구조

  • 수축 경로: 3×3 conv 2회 + 2×2 max pool을 반복하며 채널 64 → 1024
  • 확장 경로: up-conv로 해상도를 2배씩 키우고, 같은 층의 인코더 특징을 채널 방향으로 이어 붙인 뒤(concat) conv
  • 마지막 1×1 conv로 클래스 맵 출력

FCN과 무엇이 다른가

  • FCN은 스킵 특징을 더하지만(add), U-Net은 이어 붙여(concat) 세밀한 정보를 더 많이 보존
  • 디코더가 인코더만큼 깊은 대칭 구조 → 경계 복원이 정교
  • 강한 데이터 증강(탄성 변형)으로 수십 장 규모 데이터에서도 학습

영향

  • 세포·장기·종양 분할 등 의료 영상의 사실상 표준
  • 후속: U-Net++, Attention U-Net, 자동 설정형 nnU-Net
  • Stable Diffusion 같은 확산 모델의 노이즈 예측망으로도 사용

Atrous (Dilated) Convolution

  • 3×3 커널의 원소 사이에 rate − 1칸의 간격을 두고 샘플링
  • 파라미터 수와 연산량은 그대로, 수용 영역(receptive field)만 확장
  • 풀링으로 해상도를 줄이지 않고도 넓은 문맥을 볼 수 있어, 특징맵을 1/8 또는 1/16 해상도로 유지

버전별 발전

  • v1 (2014): Atrous conv + CRF 후처리로 경계 보정
  • v2: ASPP 도입, ResNet 백본
  • v3 (2017): ASPP 개선(BN, 이미지 수준 특징), CRF 제거
  • v3+ (2018): 가벼운 디코더 추가로 경계 품질 향상 → 인코더–디코더와 다중 스케일의 결합

핵심 아이디어

Faster R-CNN(탐지)에 마스크 예측 브랜치를 병렬로 추가. 박스로 객체를 찾고, 그 박스 안에서 어떤 픽셀이 객체인지를 예측합니다.

탐지 → 분할

"먼저 찾고, 그다음 분할한다(detect-then-segment)"는 인스턴스 세그멘테이션의 대표 방식을 확립했습니다.

RoIAlign

기존 RoI Pooling은 좌표를 정수 격자로 반올림(양자화)해 특징과 원본 사이에 몇 픽셀씩 어긋남이 생깁니다. 박스 분류엔 괜찮지만 마스크에는 치명적입니다.

해결

반올림 없이 실수 좌표 그대로 두고 bilinear 보간으로 특징을 샘플링 → 픽셀 정렬 오차 해소, 마스크 정확도 크게 향상

마스크 브랜치

각 RoI에 작은 FCN을 적용해 클래스별 m×m(28×28) 이진 마스크를 출력하고, 박스 크기로 되돌려 붙입니다.

분리된 학습

Softmax로 클래스끼리 경쟁시키지 않고, 분류 헤드가 고른 클래스의 마스크에만 픽셀별 Sigmoid + BCE를 적용 → "무엇"과 "모양"을 분리해 학습

이 구조는 키포인트(사람 관절) 추정으로도 쉽게 확장되며, 오랫동안 COCO 인스턴스 세그멘테이션의 기준 모델로 쓰였습니다.

두 브랜치를 하나로

Mask R-CNN에 FPN 특징을 공유하는 시맨틱 브랜치를 추가. Thing은 인스턴스 브랜치, Stuff는 시맨틱 브랜치 결과를 쓰고, 겹치는 픽셀은 규칙에 따라 병합합니다.

의미

하나의 네트워크로 파놉틱 결과를 내는 강력한 기준 모델

Mask2Former 2022

픽셀 분류 → 마스크 분류

픽셀마다 클래스를 고르는 대신, N개의 쿼리가 각각 (마스크, 클래스) 쌍을 예측합니다. DETR의 집합 예측을 세그멘테이션으로 가져온 방식입니다.

핵심

Masked attention으로 각 쿼리가 자기 마스크 영역에만 집중 → 같은 구조로 시맨틱·인스턴스·파놉틱 모두에서 당시 최고 수준

SAM 2023

Segment Anything Model (Meta)

점·박스·마스크 같은 프롬프트를 주면 해당 객체의 마스크를 출력하는 분할 파운데이션 모델. 약 1,100만 장 이미지, 10억 개 이상의 마스크(SA-1B)로 학습했습니다.

특징

처음 보는 대상도 추가 학습 없이 분할(zero-shot). 클래스 이름 대신 "마스크"만 출력 → 라벨링 도구로 널리 활용. SAM 2는 비디오, SAM 3는 텍스트 개념 프롬프트까지 확장

패러다임 변화  픽셀별 분류 (FCN · U-Net · DeepLab) → 마스크 분류 (MaskFormer · Mask2Former) → 프롬프트 기반 범용 분할 (SAM)
04 학습과 평가

세그멘테이션의 손실 함수와 평가 지표

픽셀을 맞혔는가, 그리고 영역이 얼마나 겹치는가

손실 함수 (학습)

Pixel-wise Cross-Entropy

L = −(1/N) Σ픽셀 Σc yc · log pc

픽셀 하나하나를 분류 문제로 보고 평균. 배경 픽셀이 대부분이면 작은 객체가 무시되므로 클래스 가중치를 주기도 합니다.

Dice Loss

Dice = 2|A ∩ B| / (|A| + |B|)   L = 1 − Dice

예측 영역 A와 정답 영역 B의 겹침 자체를 최적화. 전경이 아주 작은 의료 영상에서 특히 효과적이며, CE + Dice 조합이 흔합니다.

인스턴스 마스크 손실

Mask R-CNN처럼 RoI마다 이진 마스크를 예측할 때는 픽셀별 BCE를 사용합니다. Mask2Former는 마스크에 BCE + Dice, 클래스에 CE를 함께 씁니다.

평가 지표

Pixel Accuracy 가장 단순한 지표

전체 픽셀 중 맞힌 비율. 배경이 90%면 전부 "배경"이라 답해도 90%가 되어 단독으로는 부족

IoU · mIoU 시맨틱의 표준

IoUc = TP / (TP + FP + FN)   mIoU = 클래스별 IoU 평균

클래스마다 겹침을 재고 평균 → 작은 클래스도 같은 비중으로 평가

mask AP 인스턴스

Part 1의 AP와 같은 방식이지만, 박스 IoU 대신 마스크 IoU로 TP/FP를 판정합니다.

PQ (Panoptic Quality) 파놉틱

PQ = SQ × RQ
SQ = 매칭된 쌍(IoU > 0.5)의 평균 IoU
RQ = TP / (TP + ½FP + ½FN)

"얼마나 정확히 분할했나(SQ)"와 "얼마나 잘 찾았나(RQ)"를 곱해 하나로 평가

Part 1과의 연결  Mask R-CNN = Faster R-CNN + 마스크, Mask2Former = DETR식 집합 예측 + 마스크. 탐지의 발전이 그대로 세그멘테이션으로 이어집니다.

선택 기준  영역만 필요하면 시맨틱, 개체 수·개별 형태가 필요하면 인스턴스, 장면 전체를 이해해야 하면 파놉틱을 선택합니다.

정리

세그멘테이션 = 픽셀마다 무엇인지, 그리고 어느 객체인지

개념과 유형

  • 모든 픽셀에 레이블을 할당해 정확한 형태·경계 파악
  • 시맨틱(클래스) · 인스턴스(개체) · 파놉틱(통합)
  • Thing은 개체로 세고, Stuff는 영역으로 본다

핵심 원리

  • 인코더(의미) → 디코더(해상도 복원)
  • 업샘플링: 보간 · 전치 합성곱 · 언풀링
  • 스킵 연결로 경계 복원, Atrous conv로 해상도 유지

대표 모델

  • 시맨틱: FCN → U-Net → DeepLab(ASPP)
  • 인스턴스: Mask R-CNN(RoIAlign + 마스크 브랜치)
  • 통합·범용: Panoptic FPN → Mask2Former → SAM

학습과 평가

  • 손실: 픽셀별 Cross-Entropy, Dice
  • 지표: mIoU(시맨틱) · mask AP(인스턴스) · PQ(파놉틱)
  • 목적에 맞는 유형과 지표를 함께 선택
객체 탐지: 무엇이 어디에 (박스)  |  세그멘테이션: 무엇이 정확히 어느 픽셀에 (마스크)
